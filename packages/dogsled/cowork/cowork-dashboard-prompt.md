# Dogsled Dashboard Prompt

Build or refresh the local Dogsled operations dashboard for this repo.

Please:

- read `dogsled.setup.answers.yml`
- read `dogsled.setup.summary.md`
- read `dogsled.yml` if it exists
- inspect local pipeline configuration and recorded run results
- read recent local logs, validation output, and failure messages if available
- create or update a simple local dashboard in this repo
- make it understandable for a non-technical user
- summarize the current state in plain English
- highlight failures, blockers, and missing credentials
- show the next best actions Cowork can take for the user

Keep the dashboard local to the repo. Do not require a hosted service or remote MCP connector.
