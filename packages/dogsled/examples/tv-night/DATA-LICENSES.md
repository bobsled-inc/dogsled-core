# Data sources

No source records, articles, images or posters are bundled. The manifest names the sources; its initial row counts are zero. Your ETL fetches data when you run it.

- [TVmaze API](https://www.tvmaze.com/api): data is offered under CC BY-SA. Credit TVmaze, retain show URLs and follow share-alike requirements when sharing the data or adaptations. API access is public and requires no key. Use small requests and respect throttling.
- [Wikipedia reuse guidance](https://www.mediawiki.org/wiki/Wikimedia_APIs/Content_reuse): retain article title, page/revision IDs, source URL, retrieval time and the applicable license. Attribute reused text, mark changes and follow share-alike requirements for adaptations. Article excerpts may reveal plot details.
- [Wikidata licensing](https://www.wikidata.org/wiki/Wikidata:Licensing): structured data is CC0. Retain entity IDs and source links for traceability.

Data licenses are separate from the software license. Do not assume an image has the same license as article text. This walkthrough does not fetch artwork. TMDB and IMDb content are not used.
