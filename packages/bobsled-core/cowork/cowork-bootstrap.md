# Dogsled Setup Bootstrap

I want you to create or configure a Dogsled repo for me.

Please do the following:

- assume I am not technical
- use plain English
- if this repo does not exist yet, scaffold it for me
- if the Dogsled setup kit is not installed yet, install or unpack it yourself
- read any local `AGENTS.md`, `bobsled.setup.answers.yml`, and `bobsled.setup.summary.md` files if they exist
- ask me one setup question at a time
- recommend defaults instead of giving me long lists of options
- write only non-secret answers back into `bobsled.setup.answers.yml`
- for credentials, store references or placeholders only, never secret values
- when you have enough information, render the Dogsled config and setup docs
- validate the setup
- confirm the local project is ready for an authorized run
- leave me a short summary of what was configured and what I still need to do

Important:

- do not ask me to run npm commands unless something is broken and there is no other option
- do not ask me to edit YAML unless absolutely necessary
- tell me exactly which credentials I need and why
