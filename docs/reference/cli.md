# CLI reference

Every `dogsled` command and flag, as printed by `--help`. Run `dogsled <command> --help`
for the same text. This page is generated by `node scripts/docs/cli-reference.mjs`;
regenerate it after changing a command.

## `dogsled`

```text
Usage: dogsled [options] [command]

Extract, load and model data with YAML project files

Options:
  -V, --version                    Display the CLI version
  --json                           Emit all output as newline-delimited JSON
                                   (default: false)
  --verbose                        Enable verbose / debug-level output (default:
                                   false)
  --quiet                          Suppress all non-error output (default:
                                   false)
  --config <path>                  Path to a Dogsled project config file
  --project-root <path>            Dogsled Project root (default: current
                                   directory)
  --no-color                       Disable ANSI colour codes
  -h, --help                       display help for command

Commands:
  init [options] [project-name]    Initialize a new Dogsled project
  doctor [options]                 Check Dogsled project health
  extract [options]                Extractor commands
  pipeline [options]               Pipe extractor output directly into the
                                   loader

  model [options]                  Modeling commands
  query [options] <sql>            Run a SQL query against a DuckDB or BigQuery
                                   database
  source-query [options] <sql...>  Run a SQL query over sources.* with lazy API
                                   resource materialization

                                   external systems via action specs

                                   graph
```

#### `dogsled extract run`

```text
Usage: dogsled extract run [options] [resources...]

Run extraction pipeline

Arguments:
  resources                                        Resource names to extract (default: all)

Options:
  --integration <name>                             Integration to extract from
  --full-refresh                                   Ignore bookmarks and extract from the beginning
  --input <key=value...>                           Input override values (default: [])
  --default-via <id>                               Override source integration's default_transport for this run
  --resource-via <name:id...>                      Force a specific transport for one resource (repeatable). Wins over --default-via. (default: {})
  --resource-inputs-json <json>                    JSON object of per-resource input overrides: {"<resource>":{"<input>":"value"}}. Merged over --input for that resource only; array values are JSON-encoded.
  --resource-input-matrices-json <json>            JSON object of static per-resource input matrices. Each tuple is extracted into the same stream.
  --resource-input-matrix-concurrency-json <json>  JSON object of per-resource matrix concurrency values between 1 and 64.
  --output <mode>                                  Output mode: stdout or file
  --limit <count>                                  Cap number of records (for testing)
  --lint                                           Validate responses and detect schema drift
  --batch                                          Enable batch output
  --batch-format <format>                          Batch file format: jsonl or parquet
  --batch-size <count>                             Records per batch file
  --emit-model-spec-source                         Generate Model Spec source YAML alongside extraction
  --embed-config-file <path>                       Path to a JSON file with the resolved pipeline embed config (used to pre-fill embedding columns in --emit-model-spec-source scaffolds)
  --advance-state                                  Persist state after a successful run
  --no-state-write                                 Do not persist state during extraction
  --plan <name>                                    Execute only the steps in a named extract-intents plan
  --output-dir <path>                              Directory for run_summary.json output
  --timeout <ms>                                   Overall extraction timeout in milliseconds (default: "14400000")
  --max-consecutive-failures <n>                   Circuit breaker threshold (default: "5")
  --state-backend <url>                            State backend URL (file://<path> or https://...). Default: local file at config state_dir.
  --state-auth-env <var>                           Name of env var holding the Bearer token for the HTTP state backend.
  --warehouse <selector>                           Pipeline-scoped Snowflake warehouse selector
  --query-tag <tag>                                Snowflake query tag for this execution
  -h, --help                                       display help for command
```

### `dogsled runner`

```text
Usage: dogsled runner [options] [command]

Validate and run Dogsled pipelines

Options:
  -h, --help                display help for command

Commands:
  validate [options]        Validate dogsled.yml configuration
  run [options] <pipeline>  Run a single pipeline from dogsled.yml
  help [command]            display help for command
```

#### `dogsled runner validate`

```text
Usage: dogsled runner validate [options]

Validate dogsled.yml configuration

Options:
  --config <path>        Path to dogsled.yml
  --project-root <path>  Dogsled Project root (default: current directory)
  --yaml                 Output as YAML
  --strict               Treat warnings as errors
  --json                 Output as JSON
  --verbose              Enable verbose output
  --quiet                Suppress non-error output
  -h, --help             display help for command
```

#### `dogsled runner run`

```text
Usage: dogsled runner run [options] <pipeline>

Run a single pipeline from dogsled.yml

Options:
  --config <path>                 Path to dogsled.yml
  --project-root <path>           Dogsled Project root (default: current
                                  directory)
  --full-refresh                  Ignore bookmarks and extract from the
                                  beginning
  --reconcile-schema <stream...>  One-shot Snowflake schema reconciliation
                                  (requires --full-refresh)
  --resource <name...>            Specific resources to extract
  --json                          Output machine-readable JSON logs
  --verbose                       Enable verbose output
  --quiet                         Suppress non-error output
  -h, --help                      display help for command
```

### `dogsled learn`

```text
Usage: dogsled learn [options]

Interactive CLI tutorial — learn Dogsled step by step

Options:
  --list            Show all phases with progress
  --reset           Clear all progress
  --section <name>  Jump to a named section (e.g. "Phase 4")
  --goto <n>        Jump to lesson number N
  --auto            Auto-advance on success (1.5s delay)
  --cli <cmd>       Override CLI binary (default: DOGSLED_CLI env or "dogsled")
  -h, --help        display help for command
```
