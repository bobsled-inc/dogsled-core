# Support

Ask usage questions and share ideas in [GitHub Discussions](https://github.com/bobsled-inc/bobsled-core/discussions).
Report reproducible bugs through [GitHub issues](https://github.com/bobsled-inc/bobsled-core/issues/new/choose).
Report vulnerabilities privately using the process in [SECURITY.md](SECURITY.md).
For other private matters, such as Code of Conduct reports, email `maintainers@bobsled.co`.
