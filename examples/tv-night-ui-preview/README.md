# TV Night tutorial UI prototype

Open [index.html](./index.html) locally to review the proposed tutorial UI. The
HTML contains its JavaScript, styles, fonts, logo, and saved snapshot. Viewing it
requires no installation, credentials, server, or network connection.

This is a standalone design prototype. It does not replace the CLI's tutorial
renderer or run an API connection, pipeline, database query, or AI transformation.
All six shows, eighteen episodes, working definitions, and completed checkpoints
are synthetic. The remaining chapters show their intended outcomes and available
inputs without inventing results.

## Review the experience

- Browse chapters with the expanded sidebar or Previous / Next step actions.
- Switch between Shows and Episodes with tabs; use search to filter saved rows.
- Open a record to inspect its fields, including the deliberately missing runtime.
- Explore the chapter's working files and its elbow-routed dependency graph.
- Mark a completed chapter as reviewed. The state applies only to this view and
  resets when the page reloads.
- Copy the visible request under “Share this with your agent”. This copies text
  for a conversation; it does not send a message or invoke an agent.
- Use More for the theme command and archived layout comparisons.

The archived comparison pages preserve earlier visual references. Their agent
prompts refer to the earlier dummy runner; use the current preview for the proposed
handoff experience.

## Source and fixtures

`src/` contains the React composition, chapter-specific content, small dependency
layout, and feature layout styles. Components and theme styles are compiled from
the public export boundaries of the Dogsled UI design system. The generator
embeds the canonical brand assets instead of fetching them.

`fixtures/catalog.json` and `fixtures/snapshot.json` contain the synthetic input
and saved result. `manifest.json` records source fingerprints, bundled dependency
versions, and output hashes. Required third-party notices are under `LICENSES/`;
React, Radix, and other runtime packages retain their upstream licenses. The
composition and fixtures follow this repository's license. The archived original
layout comes from the Dogsled Core tutorial renderer.

## Verify the checked-in preview

From the repository root, run:

```sh
node examples/tv-night-ui-preview/verify.mjs
pnpm exec vitest run --config vitest.structural.config.mjs tests/structural/tutorial-ui-preview.test.mjs
```

These checks need only the repository's existing tools. They verify output
integrity, embedded assets, synthetic data, and local comparison destinations.
They do not perform visual browser review.

## Rebuild or run interaction checks

Rebuilding requires a prepared Dogsled UI workspace with its existing build and
test dependencies. No dependency on that workspace is added to the CLI or its
published package. Set `DOGSLED_UI_ROOT` explicitly:

```sh
cd examples/tv-night-ui-preview
export DOGSLED_UI_ROOT=/path/to/ui-workspace
node build.mjs
node check.mjs
"$DOGSLED_UI_ROOT/node_modules/.bin/tsc" -p tsconfig.json
```

The build writes `index.html`, `manifest.json`, and license notices. Temporary
bundles and the generated TypeScript configuration are ignored. A different saved
snapshot can be passed as the first build argument. Comparisons are archived
snapshots and are not regenerated by this command.

Interaction checks exercise hydration, chapter navigation, result tabs and
keyboard activation, filtering, record inspection, files, lineage, themes,
review state, and exact clipboard handoff with manual-copy fallback. Browser
visual review remains a separate step.
